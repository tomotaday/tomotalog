# ともたろぐ

生活を振り返るためのカレンダー型生活ログ

関数よりPivotが好きだった。

⸻

## コンセプト

ともたろぐは、家計簿を作るために生まれたアプリではありません。

一つの生活データを、
さまざまな視点から何度でも振り返るための
生活ログです。

Googleマップのタイムラインが
「時間」で生活を振り返るように、

ExcelのPivotTableが
「視点」を自由に切り替えられるように、

ともたろぐは、その二つを融合したアプリを目指しています。

データは一つ。見方は無限。

年月が経つほど価値が増していく

「データの複利」

これが Version2 の設計思想です。

⸻

## 現在のバージョン

**Ver 2.7.3 - 2026/08/23**

### テーマ

**タイムラインを、暮らしとして見える形へ育てる。**

Ver2.7.3では、実データを使ったタイムライン試験展示をさらに進め、
Googleタイムラインの記録上生じる空白や日付またぎなどを、
ともたろぐ側で生活履歴として自然に見えるよう補完する仕組みを追加しました。

また、訪問図鑑に登録された場所を基準としてタイムライン上の地点を扱い、
複数のPlaceIDを一つの場所としてまとめて管理できる構造を
表示・判定の両方へ反映しました。

タイムライン上の表示についても、
訪問図鑑の「ともた分類」を利用した簡潔な表示へ改善し、
情報量を抑えながら場所を把握しやすい表示を試験しています。

さらに、タイムラインの移動手段など、
各機能で使用する表示上の置き換えルールを
［マスター管理］から管理できる基盤を整えました。

今回は完成版の表示仕様を決めるのではなく、
実データを使いながら、

- 生活履歴として自然に見えるか
- 必要な情報量はどの程度か
- どこまで自動補完するべきか
- ともた分類による簡潔表示が見やすいか
- 表示置き換えをどのように育てていくか

を確認しながら育てています。

Version2.7では、

**保存した生活履歴を、壊さず、読みやすく、使いやすく育てること**

を重視していきます。

⸻

## マスター管理

生活データで使用する共通情報や、
表示上の置き換えルールを管理します。

### タグ設定

タグ・カテゴリなど、
生活ログで使用する分類情報を管理します。

### 支払方法設定

支払方法を独立して管理します。

### 表示置き換え

元データを変更せず、
ともたろぐ上での表示方法だけを置き換えるための管理機能です。

置き換え対象となる機能・画面を見出しとして表示し、
どこへ反映されるルールなのかを確認できるようにします。

例：

* 【タイムライン】WALK → 🚶‍♀️
* 【タイムライン】DRIVE → 🚗
* 【訪問図鑑】ともた分類 → 表示用アイコン・名称

表示置き換えは、
今後さまざまな機能へ追加できる共通基盤として育てていきます。

## Version2 の考え方

Version2では、

生活データを役割ごとに分離して管理します。

Googleタイムライン研究所
（隔離実験区域）
        │
        ▼
正式タイムライン格納庫
（生活履歴）
        │
        ▼
訪問図鑑
（場所マスター）

研究所は、

UIや処理方法を検証するための実験場です。

正式実装では、

タイムライン格納庫が生活履歴を管理し、

訪問図鑑が場所そのものを育てます。

場所の身元情報は共有し、

訪問実績は由来ごとに保持します。

また、複数のPlaceIDが一つの訪問図鑑へまとめられている場合は、
それらを同一の場所として扱います。

保存は独立。

表示は自由。

元データは変更せず、
ともたろぐ側で必要な表示上の読み替えや補完を行います。

それぞれの事実をそのまま残し、

あとから自由に結び付けること。

一つのデータを、

さまざまな見せ方で振り返ること。

それが、ともたろぐ Version2 の目標です。
