ともたろぐ

生活を振り返るためのカレンダー型生活ログ

関数よりPivotが好きだった。

⸻

コンセプト

ともたろぐは、家計簿を作るために生まれたアプリではありません。

一つの生活データを、
さまざまな視点から何度でも振り返るための
生活ログです。

Googleマップのタイムラインが
「時間」で生活を振り返るように、

ExcelのPivotTableが
「視点」を自由に切り替えられるように、

ともたろぐは、その二つを融合したアプリを目指しています。

データは一つ。見方は無限。

年月が経つほど価値が増していく

「データの複利」

これが Version2 の設計思想です。

⸻

現在のバージョン

Ver 2.8.1 - 2026/09/02

テーマ

タイムラインを、正しく読み、簡潔に見せる。

Ver2.8.1では、
Googleタイムラインの実データを
ともたろぐ側の表示ルールによって
より正確に解釈できるよう改善しました。

特に、複数日にまたがる長時間のVisitや、
連続する空白日、
日付をまたぐ短時間移動などについて、
単純な日単位の表示ではなく、
元データの時間情報をもとに
対象期間全体を解釈する構造へ整理しています。

また、場所の同一性や滞在・宿泊などの判定では、
Google Place IDそのものではなく、
ともたろぐの「訪問図鑑レコード」を
場所の基本単位として扱います。

これにより、
複数のPlace IDを一つの訪問図鑑へまとめた場合でも、
タイムライン上では同じ場所として扱える構造を維持します。

表示は、
「ともた分類 店名」を基本とした
簡潔な一行表示へ整理しています。

タグについては、
タイムライン上の生活記録に対して
日単位で扱う構造へ整理しました。

2.8.0で始まった

「記録を表示する」から
「記録を解釈し、彩る」へ。

という考え方を、
2.8.1ではタイムラインの実データ解釈へ
さらに具体化しています。

マスター管理

生活データで使用する共通情報や、
表示上の置き換えルールを管理します。

タグ設定

タグ・カテゴリなど、
生活ログで使用する分類情報を管理します。

タイムラインでは #、
家計簿では ＊ を先頭に付けることで、
同じ単語を使用しながら
付与元を区別できる構造を目指します。

例：

* #北海道
* ＊北海道

支払方法設定

支払方法を独立して管理します。

表示置き換え

元データを変更せず、
ともたろぐ上での表示方法だけを置き換えるための管理機能です。

置き換え対象となる機能・画面を見出しとして表示し、
どこへ反映されるルールなのかを確認できるようにします。

例：

* 【タイムライン】WALK → 🚶‍♀️
* 【タイムライン】DRIVE → 🚗
* 【訪問図鑑】ともた分類 → 表示用アイコン・名称

表示置き換えは、
今後さまざまな機能へ追加できる共通基盤として育てていきます。

タグと検索

タイムラインと家計簿では、
同じ言葉をタグとして使用できます。

例：

* #北海道 → タイムライン
* ＊北海道 → 家計簿

タグは現在、
タイムライン上の生活記録を確認するための
情報として利用します。

将来的には、
タグだけを対象とした検索にも対応し、

「北海道」

なら共通するタグを検索し、

「#北海道」

ならタイムラインのみ、

「＊北海道」

なら家計簿のみ、

という検索ができる構造を目指します。

Version2 の考え方

Version2では、

生活データを役割ごとに分離して管理します。

Googleタイムライン研究所
（隔離実験区域）
│
▼
正式タイムライン格納庫
（生活履歴）
│
▼
訪問図鑑
（場所マスター）

研究所は、

UIや処理方法を検証するための実験場です。

正式実装では、

タイムライン格納庫が生活履歴を管理し、

訪問図鑑が場所そのものを育てます。

場所の身元情報は共有し、
訪問実績は由来ごとに保持します。

また、複数のPlaceIDが一つの訪問図鑑へまとめられている場合は、
それらを同一の場所として扱います。

保存は独立。

表示は自由。

元データは変更せず、
ともたろぐ側で必要な表示上の読み替えや補完を行います。

そしてVersion2.8からは、

記録を表示するだけではなく、
ともたろぐ自身のルールで解釈し、彩る

という考え方を加えます。

Version2.8.1ではさらに、

元データを正しく読むこと。

を重視します。

長時間の記録を日単位に分断せず、
時間情報をもとに対象期間を解釈する。

場所をGoogle Place ID単位ではなく、
ともたろぐの訪問図鑑単位で扱う。

そして、その結果を
簡潔で読みやすい表示へ変換する。

それによって、

事実を正しく残し、
その事実をともたろぐのルールで読み、
見やすく彩る。

という流れを育てていきます。

それぞれの事実をそのまま残し、

あとから自由に結び付けること。

一つのデータを、

さまざまな見せ方で振り返ること。

そして、

そのデータにともたろぐ自身の意味を重ね、
生活史として育てていくこと。

それが、ともたろぐ Version2 の目標です。
