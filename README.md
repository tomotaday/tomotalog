# ともたろぐ

生活を振り返るためのカレンダー型生活ログ

関数よりPivotが好きだった。

⸻

## コンセプト

ともたろぐは、家計簿を作るために生まれたアプリではありません。

一つの生活データを、
さまざまな視点から何度でも振り返るための
生活ログです。

Googleマップのタイムラインが
「時間」で生活を振り返るように、

ExcelのPivotTableが
「視点」を自由に切り替えられるように、

ともたろぐは、その二つを融合したアプリを目指しています。

データは一つ。見方は無限。

年月が経つほど価値が増していく

「データの複利」

これが Version2 の設計思想です。

⸻

## 現在のバージョン

**Ver 2.7.2 - 2026/08/22**

### テーマ

**タイムラインの実データを、生活ログで試験展示する。**

Ver2.7.2では、これまでダミー表示だった
「🗺️ タイムラインを見る」を、
タイムライン格納庫に保存されている実データを
読み取り専用で表示する試験展示へ置き換えました。

前日／翌日の切替に対応し、
既存の移動手段の読み替え表示や
訪問図鑑への導線も維持しています。

今回は完成版の表示仕様を決めるのではなく、
実データを実機で確認し、

- 1日分の情報量
- 表示する情報／省略する情報
- 縦方向の長さ
- 操作感

などを観察する段階です。

Version2.7では、

**保存した生活履歴を、壊さず、読みやすく、使いやすく育てること**

を重視していきます。

## Version2 の考え方

Version2では、

生活データを役割ごとに分離して管理します。

Googleタイムライン研究所
（隔離実験区域）
        │
        ▼
正式タイムライン格納庫
（生活履歴）
        │
        ▼
訪問図鑑
（場所マスター）

研究所は、

UIや処理方法を検証するための実験場です。

正式実装では、

タイムライン格納庫が生活履歴を管理し、

訪問図鑑が場所そのものを育てます。

場所の身元情報は共有し、

訪問実績は由来ごとに保持します。

保存は独立。

表示は自由。

それぞれの事実をそのまま残し、

あとから自由に結び付けること。

一つのデータを、

さまざまな見せ方で振り返ること。

それが、ともたろぐ Version2 の目標です。
